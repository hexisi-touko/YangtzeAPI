# 令牌、用量与计费

这一组负责“成员用什么 Token 调用、用了多少、扣多少额度，以及管理员如何查看统计”。这里的 Token 是 New API 发给成员的下游密钥，不等于上游厂商密钥。

## 建议顺序

1. `token.go`：创建、修改、禁用和查询下游 Token。
2. `billing.go`、`usedata.go`：订阅/用量概览和按时间统计。
3. `pricing.go`、`ratio_config.go`：模型价格与倍率配置。
4. `relay.go`（见上一组）：请求完成时如何触发额度处理。
5. `codex_usage.go`、`prefill_group.go`、`ratio_sync.go`：专项用量、预填充分组和倍率同步。
6. `log.go`：请求日志和用量日志的查询。

## 文件地图

- `token.go`：成员 API Token 的生命周期、分组和额度字段。
- `billing.go`：订阅和用量汇总接口。
- `usedata.go`：按用户、日期等维度查询额度使用情况。
- `pricing.go`：模型价格和倍率展示/重置。
- `ratio_config.go`、`ratio_sync.go`：倍率配置读取和同步。
- `prefill_group.go`：预填充分组管理。
- `codex_usage.go`：Codex 渠道用量和速率限制信息。
- `log.go`：管理员和普通用户查看请求/用量日志。

## 关联位置

额度数据通常落在 `model/`，业务计算在 `service/` 或 relay 相关代码。学习时要区分：认证 Token 决定“能不能调用”，计费逻辑决定“调用后扣多少”。
